Política de privacidade

Jarvis — assistente pessoal · atualizada em 24 de setembro de 2026

O Jarvis é um assistente pessoal auto-hospedado, de uso privado e com um único usuário autorizado. Esta política descreve como ele trata os dados obtidos das APIs do Google.

Dados acessados

O aplicativo solicita um único escopo: https://www.googleapis.com/auth/calendar.events.

Com ele, acessa exclusivamente os eventos da agenda da conta Google que concedeu a autorização: título, data, horário, local, descrição e participantes. Nenhum outro dado da conta Google é lido, e nenhum outro serviço do Google é acessado — em particular, não há acesso a e-mail, contatos, arquivos ou fotos.

Finalidade

Os dados são usados apenas para executar os pedidos feitos pelo próprio titular da conta: consultar compromissos, criar eventos, alterar e remover eventos.

Armazenamento

O aplicativo roda em servidor controlado pelo titular. As credenciais de acesso ficam apenas nesse servidor, em arquivo restrito. Dados de eventos são lidos sob demanda no momento de cada pedido e não são copiados para banco de dados nem mantidos após a resposta.

Compartilhamento

Nenhum dado obtido das APIs do Google é vendido, alugado, compartilhado ou transferido a terceiros. Não há serviço de análise, rastreamento, publicidade ou telemetria. O aplicativo não possui outros usuários com quem compartilhar dados.

Uso limitado

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Retenção e revogação

O titular pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. A revogação invalida imediatamente as credenciais armazenadas. As credenciais também podem ser apagadas diretamente no servidor.
